# CiteWeave Reliability Benchmark

**Benchmark version:** 0.3

## 1. Task families

### A. Pipeline integrity

- acquisition count and truncation status;
- exact and source-identifier deduplication;
- canonical primary/foreign-key integrity;
- field coverage and analyzability;
- network node/edge invariants;
- deterministic layout and figure QA;
- raw-to-claim evidence reachability;
- final package hash and structural validation.

### B. Graph factual questions

- node and edge counts;
- highest weighted-degree node;
- strongest edge and its weight;
- cluster count and membership;
- local neighborhood and path questions;
- cross-community bridge questions;
- explicitly unanswerable or false-premise questions.

### C. Narrative interpretation

Responses are decomposed into atomic claims and labelled as:

- **entailed** — fully supported by the cited graph/table evidence;
- **contradicted** — conflicts with the evidence;
- **not verifiable** — evidence is insufficient;
- **non-empirical** — methodological or rhetorical statement.

Only empirical claims enter factuality metrics.

### D. Selective human review

Each stage item receives:

- detector outputs;
- estimated risk;
- escalation decision;
- human decision when escalated;
- later audit decision for a stratified sample of auto-accepted items.

## 2. Primary metrics

Let `TP` be supported empirical claims, `FP` unsupported or contradicted claims,
`FN` omitted required gold facts, `H` human interventions, and `N` eligible
items.

### Atomic claim precision

`ClaimPrecision = TP / (TP + FP)`

### Unsupported-claim rate

`UCR = FP / (TP + FP)`

This is the primary operational hallucination metric. It is reported overall
and by error class. In the constrained graph-copy task, a statement is scorable
when it is a nonempty natural-language claim rather than a raw JSON fragment.
Support is exact after Unicode NFKC, case, hyphen, whitespace, and terminal-
punctuation normalization because the model is instructed to copy a supplied
fact. Claim coverage must always accompany UCR.

### Gold-fact recall

`GoldRecall = TP / (TP + FN)`

### Evidence-path validity

`EPV = valid cited evidence paths / all cited evidence paths`

A path is valid only when all referenced nodes/edges exist and the path entails
the claim. EPV is evaluated only for non-abstained answers, and an answered
claim with no cited evidence is invalid. Evidence recall is reported separately;
an all-abstain system therefore cannot obtain a high EPV by vacuous truth.

### Abstention F1

Unanswerable items are positive cases. Correct abstention is a true positive.

### Human intervention rate

`HIR = H / N`

HIR is never interpreted without the quality achieved on auto-accepted items.

### Selective risk

`SelectiveRisk(c) = errors among auto-accepted items at coverage c / auto-accepted items`

Report the risk-coverage curve and area under the risk-coverage curve.

## 3. Secondary metrics

- exact answer accuracy for structured graph questions;
- schema-valid output rate;
- structured unsupported-answer rate;
- format-failure rate;
- statement-claim coverage;
- evidence citation precision and recall;
- detector recall for critical errors;
- human override rate;
- mean and median review seconds;
- tokens, latency, and monetary cost;
- run-to-run consistency;
- Brier score and expected calibration error when probabilities are available.

Text-overlap metrics are diagnostic only and are not evidence of factuality.
LLM-as-judge scores may be reported only alongside human-validated estimates and
with blinded condition labels.

## 4. Quality gates

An experimental condition passes only if:

- schema-valid output rate >= 0.95;
- claim precision >= 0.95 for the proposed production setting;
- evidence-path validity >= 0.95;
- critical-error detector recall >= 0.95;
- acquisition and canonical integrity gates pass;
- all exclusions are documented.

For RQ2, success requires a lower HIR than cold start while the one-sided 95%
Clopper-Pearson lower bound for precision on retrospectively annotated
auto-accepted items is at least 0.95. A lower HIR alone is a failure.

For RQ3, success requires lower paired UCR than the no-graph baseline and no
material loss of gold-fact recall. Statistical significance and effect size are
both reported.

## 5. Gold construction

Structured graph answers are generated by deterministic recomputation from
frozen node and edge tables. A separate verifier recomputes each answer rather
than trusting the file that created the visualization.

Narrative claims are independently labelled by two reviewers. Disagreements are
adjudicated. Report agreement before adjudication.

The current automated experiment uses exact-normalized scoring only for copied
atomic statements. This does not replace independent annotation for open-ended
narrative interpretations.

## 6. Statistical analysis

- topic-stratified bootstrap, 10,000 resamples, for metric confidence intervals;
- paired bootstrap for differences in UCR and recall;
- McNemar test for paired correctness/incorrectness;
- Holm correction for multiple primary condition comparisons;
- odds ratios or absolute risk differences as effect sizes;
- mixed-effects logistic regression with random intercepts for topic and
  question when sample size permits.
