# 结果前图身份完整性发现（2026-08-27）

## 结论

当前正式作者网络题不能执行。问题不是LLM回答差，而是图把缺失作者ID统一写成`openalex-author:None`，把互不相同的署名合并为伪枢纽。4个主主题的20个作者网络题全部在核心算子/答案材料中引用该节点。正式API监督器已停止，并增加持久hold；旧冻结版本完整保留，没有用删除失败题来维持通过率。

这也说明：算子重放成功不等于研究数据有效。用独立SciPy稀疏实现复核原图的12个路径/删边/删点算术项，12/12符合已登记数值，但修复身份后12/12发生变化或原锚点失效。

不同署名数不是不同真实人数；同一人的多种拼写也可能存在。原始署名计数来自压缩原始采集页，论文计数来自去重后的canonical关系，因此分母不同。四个复制语料也存在同类错误，但其当前正式题只使用关键词图。

还有`openalex-source:`这一未知发表来源桶，已披露为尚未解决的元数据问题；本次不把它当作真实期刊，也不借作者修复改动未注册的来源统计。

## 为什么必须重建全部作者题

四个主主题原“最高加权度枢纽”和选中的反事实边都使用了这个错误节点。身份修复后，这8个删除实验的锚点不再存在；钙钛矿多跳题还有一个端点失效。其他三个路径题中：

- 联邦学习医疗：原逆权距离1.924242，修复后两端不再连通。
- 绿氢电解：1.333333变为2.583333。
- 肿瘤空间转录组：1.059524变为1.333333。

不能只替换文章中一个人名：社区、排名、路径和基于它们选择的题目都可能改变。全部20个作者题必须按原选择算法与种子重新构建，并让所有条件共享同一份修正证据。

上述检验只独立复核路径距离和删除算术，不验证最高介数边选择、社区划分或全部答案字段。修正后仅有3个旧路径锚点仍可计算；它们在未截断作者图上的距离/不连通状态与修正后的候选图相同，不能据此声称全面的规模稳健性。
