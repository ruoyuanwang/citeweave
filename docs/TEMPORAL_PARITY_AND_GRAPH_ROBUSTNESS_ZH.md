# 时间证据公平性与图结论稳健性（2026-08-27）

## 核心判断

复杂题不能只对Graph Program提供计算所需的原始信息，再把其他方法的失败全部解释为推理能力差。当前已完成信息充分性诊断：8主题、3尺度的24道时间—结构题，全部能构造“六类静态上下文的模型请求完全相同，但正确时间答案不同”的反例。该结果是输入不可识别性证据，不是新的模型准确率结果。

反例把最早三个与最近三个观测年份进行一一交换。所有论文—关键词归属不变，因此全时段节点频数和共现图不变；年份聚合和增长候选会变化。程序先从修正版canonical表重新核算原趋势表并逐项核对，然后计算替代答案，验证实际消息序列化完全相同。比较发生在分词裁剪前；相同输入经过同一确定性裁剪仍相同。

已核验的六类上下文为flat hybrid、TF-IDF、BM25、LSA、query-subgraph、hierarchical GraphRAG v2。新版neural sidecar尚在构建，未计入这六类实测结果。不能把该审计扩大解释为所有非时间任务失效。

## 对正式论文结论的约束

1. 原冻结实验、题目、模型、预算和统计检验保留，不删除时间题，不用新结果替换旧结果。
2. 原时间题的方法差距包含时间信息与操作定义可见性差异，不能直接称为纯GraphRAG推理优势。
3. 原主分析之外，明确分开报告时间和非时间任务；不靠事后筛选有利任务制造显著性。
4. 新增同信息控制后，若差距消失，应把原优势归因于证据/工具访问，而不是图序列化本身；若仍有差距，也必须再结合同信息flat-program等消融解释。

## 已冻结的96请求补充控制

8主题×3尺度×4方法：flat hybrid、BGE-M3 neural、hierarchical GraphRAG v2、Graph Program。

每个方法获得完全相同的原始关键词—年份计数表，以及窗口、平滑、候选筛选和并列排序的操作定义。附录不包含已选中的关键词、计算后的增长率、加权度或社区归属。原检索出的图记录和原金标准答案保持不变。

共享附录每主题实测742–1,024个token，固定保留在8,192-token总上下文预算内；图检索部分沿用原160-record上限和确定性裁剪。附录最多15条原始时间序列，不是给Graph Program额外预算。不会重新编码百万条图记录：neural部分复用正在生成的冻结sidecar，仅改变所有方法共享的输入附录。

这个控制同时补足原始时间信息和明确的任务定义，因此原条件到新条件的增益不能被称为“仅增加时间数据的因果效应”。准确率按原答案及1e-4数值容差计算；时间表引用是新增合法证据，跨面板evidence-F1不直接比较。以8主题为描述性配对单位报告区间，不追加确认性显著性主张。

当前状态：科学方案、8份共享附录及源题映射已冻结；96个完整预算裁剪请求仍等待原neural/资格检查完成。`materialize_temporal_control_requests.py`实际执行被原资格缺失门禁拦住。独立执行器已实现并通过解析、弃权、重复结果、身份漂移及终止规则测试；执行器冻结也按预期被“96个请求未物化”门禁拦住。最终请求级/执行器冻结及真实调用尚未发生。补充调用排在主面板与已排期的16篇机器稿之后，避免同一API并发使用。所有完整响应都终止该cell，不因质量差重新生成。

## 已完成的144组图稳健性计算

每个主题18种设置：基线；边权阈值2/3/5；Louvain额外种子0/1/17；分辨率0.5/1.5/2；1%/5%删边各3种固定随机次序；时间窗口2/4年。单因素改变，不是完整因子交互实验。

保留全部基线节点，删边形成的孤立点不能从分母消失。路径固定端点，桥边与删除枢纽固定原锚点；社区和时间角色允许按同一规则重新选择。分别记录数字变化、锚点是否仍适用、代表节点变化及社区成员ARI/Jaccard，不比较任意社区编号是否相等。最高介数边的重新选择没有在这个附录中复算，不能宣称它已经得到稳健性验证。时间窗口只改变计数聚合，图仍是全时段图，候选仍限于原来的top-keyword表。

研究依据不是“换几个seed就能证明正确”：模块度存在大量相近得分而成员划分不同的解，必须检验解释对划分的依赖；Louvain也不自动保证社区连通性，所以额外记录了不连通社区数量。[Good等](https://arxiv.org/abs/0910.0165)、[Traag等](https://www.nature.com/articles/s41598-019-41695-z)

144/144组现已全部完成；8主题40项基线的选定字段重算均与冻结答案一致。它不是全部算子选择的独立验证。真实结果如下：

| 扰动 | 观测 | 可支持的解释 |
|---|---|---|
| 阈值或随机删边，72组 | 固定端点路径距离69/72不变；固定边删除后的冗余性判断72/72不变 | 这些具体锚点上的计算结论较稳定；没有重新检验“最高介数边”的选择 |
| 只换社区seed，24组 | 全分区ARI均值0.721、最低0.429；主导/对外联系角色所选社区成员Jaccard均值0.606/0.337 | 即使原始图不变，角色解释所对应的成员群也可能明显变化 |
| 社区分辨率0.5 | 7/8主题不足两个符合原规则的可比较社区 | 这些角色对照在该设置下不可定义，不能当作稳定结果或悄悄排除 |
| 时间窗口2/4年，16组 | 5/16选择了不同的新兴关键词；2/16的同社区判断改变 | “新兴”及其结构位置依赖窗口，不宜写成无条件领域趋势 |

种子、分辨率和时间窗口单独变化时图结构本身不变，所以这些设置下路径和删除数值不变是预期的，不计入上述72组真正的拓扑扰动证据。

还做了一个明确标注为事后描述性分解的检查：阈值改变后，“删枢纽后的最大连通分量占比”最大下降44.45个百分点，但不能把全部下降归因于删除枢纽。以医学影像主题、边权阈值5为例：阈值先把删除前占比降到56.75%，删除枢纽后为55.50%；删除本身损失1.25个百分点，相比基线多损失1.20个百分点。全部24个阈值设置中，额外的边际删除损失最大为2.60个百分点。原始图稀疏化效应和删除效应必须分开报告。

以上均是固定图、固定锚点与指定扰动下的描述性结果，没有显著性主张，不是模型或真人效果。所有结果与已冻结的正式作者输入和真人审核包分开，未因看到扰动结果而改写主实验材料。

## 对人审和文章改写的实际启示

后续版本应区别三类审核：计算错误、参数依赖未交代、由结构过度推断领域含义。不能因为一次算子重放通过，就放行“主导研究主题”“新兴方向”“不可替代枢纽”等高层解释。也不能因为换参数后结果改变，就否定原配置下算对的数值；应要求限定条件、稳健性范围和替代解释。

这还不是已经验证的主动人审策略。原真人审核抽样、预算和盲评包保持冻结，不把这批观察结果偷偷用于重排正式审核案例。它为后续版本提供待验证的审核依据，而真实人审收益仍要由独立专家数据证明。
