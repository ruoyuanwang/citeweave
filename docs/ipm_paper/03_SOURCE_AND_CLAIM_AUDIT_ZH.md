## 4. 针对本项目的实质检查

1. **结果前写作**：第 1–3 节不使用旧实验的有利数字，不把 pilot 当确认性证据；第 6、8 节明确留空。
2. **非首创声明**：不声称首次自动综述、首次使用图、首次多阶段写作、首次加入人工审核或首次程序辅助推理。
3. **程序边界**：第 3.2 节披露预注册程序、支持证据装配与非 oracle 路径的区别。对应源码 `graph_discovery.py` 的 oracle seeds、program_context 和 operator_trace；不能声称已验证任意问题的自主规划。
4. **数据边界**：图是候选截断图，不等于未截断语料实体图；可复算不意味着身份正确。
5. **语义边界**：引文和证据 ID 的存在不自动证明论断成立；结构扰动不是因果识别。
6. **审核边界**：传播仅保证已显式表示的依赖；规则启用是留出验证后的条件性操作，不是自动学习到真人偏好的既成结果。
7. **评价边界**：支持度、领域具体性、研究效用和可追溯性分别评价；非劣效不能被表述为全面超越人类。
8. **治理边界**：不编造作者、机构、资助、伦理批准、参与人数、知情同意或公开数据承诺。
9. **冻结边界**：新目录中的 RQ1–RQ3 仅为写作组织标签，不修改 H/C/A 等冻结假设。
